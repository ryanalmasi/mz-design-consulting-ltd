Grading design for a 22-hectare residential subdivision where the initial layout
would have required importing fill. Adjusting road profiles and lot grading targets
against the existing terrain brought the site into earthwork balance.

Achieving balance removed the import entirely. On a site of this size that is a
material line item, and it also removes the haul traffic that would otherwise have
run through the surrounding road network for the duration of the earthworks.
