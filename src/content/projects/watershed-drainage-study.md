An assessment of the existing drainage network across a municipal watershed,
identifying where capacity was insufficient for the current design standard and
where upstream development had changed the runoff the system receives.

The study modelled the catchment, tested the existing structures against the design
storm, and set out a prioritised list of upgrades with the reasoning behind the
ranking so the municipality could stage the work against its capital budget.
